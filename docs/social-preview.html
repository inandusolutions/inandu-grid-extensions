Inandu.Grid.Extensions

nuget: Inandu.Grid.Extensions
Turns an <inandu-grid serverSide> request into a single paged database query — paging, sorting, filtering, grouping, aggregates and keyset cursors.
MIT .NET 8 & 10 EF Core zero deps (core)
github.com/inandusolutions/inandu-grid-extensions
// ASP.NET Core — one call does paging,
// sorting, filtering & grouping in one query

app.MapGet("/api/accounts",
    (HttpRequest req, AppDb db) =>
        db.Accounts
          .AsNoTracking()
          .ToInanduGridAsync(
              req.QueryString.Value));
